# 🧠 OutfitAI – AI-Powered Clothing Recommendation App (Mobile)

OutfitAI is a mobile application that recommends daily outfits based on **weather**, **personal style**, **color preferences**, **uploaded clothing images**, and **planned activities** using artificial intelligence. The app helps users quickly decide what to wear, reducing decision fatigue and saving time each morning.

---

## 🎯 Purpose

The goal is to offer smart outfit suggestions tailored to each user by analyzing:
- Real-time weather conditions
- Daily events and activities (processed with NLP)
- Style and color preferences
- Clothing items uploaded by the user

OutfitAI uses AI to enhance the decision-making process, making it easier and more enjoyable for users to get dressed each day.

---

## 🧰 Technologies Used

### 📱 Mobile App
- **React Native** – Cross-platform mobile app development (iOS & Android)

### 🤖 AI & Backend
- **Python**
- **Flask** – For serving API requests and AI model integration
- **Scikit-learn** – For building the machine learning recommendation engine
- **Gemini API** – To analyze user input with natural language processing (NLP)

### ☁️ External Services
- **WeatherAPI** – To fetch real-time weather data
- **Polyvore Dataset** – Used for training the clothing recommendation model

### 🗃️ Database
- **PostgreSQL** – To store users, outfit history, and preferences
